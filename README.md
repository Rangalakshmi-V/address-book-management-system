# Address Book Management System Using C

## Project Overview
A menu-driven application developed using C to manage contact information.

## Features
- Add new contacts
- Search contacts by name, phone number, or email
- Edit existing contacts
- Delete contacts
- Display all contacts
- Validate phone numbers and email addresses
- Save and load contact details using file(CSV format)

##Technologies Used
- Programming Language: C
- Compiler: GCC
- Concepts: Structures, Arrays, Functions, Pointers, and Strings
- File Handling: Store and retrieve contact details using database.csv
  
## Compile
gcc main.c addressbook.c -o addressbook

## Learning Outcomes
This project helped me practise C programming, input validation, and file handling.
